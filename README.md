# vintagefs for Mavericks

Mac OS X 10.9 refuses DiskCopy 4.2 and Disk Copy 6 (NDIF) images, the formats classic Mac software and floppies
were kept in: "legacy image should be converted". With vintagefs installed, `hdiutil attach` opens them, and so does a double-click on files that still carry their
Disk Copy file type (a file that lost it, say through a zip, opens only with `hdiutil attach` for now).
